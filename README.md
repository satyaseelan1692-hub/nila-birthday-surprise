# For Nila, with love

A romantic birthday website with five questions and a cinematic video.

Open index.html in a browser, or serve this folder with `python -m http.server 8765`.

The first question offers A-D options; B, On the street, is correct. The following three questions accept any choice. The fifth is a personal love note. Answers remain in page memory and are not sent or saved.

The included movie uses Annakiliye and all 110 distinct photos. Assets are personal and are not licensed for reuse.

This repository is private. Uploading it to GitHub does not publish a live website. The question flow is a playful surprise, not a security barrier.
